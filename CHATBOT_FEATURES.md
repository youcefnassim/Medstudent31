### 📝 2. Exam Preparation Mode
**Purpose:** Interactive quiz system for self-assessment

**Subjects Available:**
- Anatomie (4 questions)
- Physiologie (4 questions)
- Biochimie (3 questions)
- Pharmacologie (3 questions)
- Pathologie (2 questions)

**Question Features:**
- Multiple choice format (A, B, C, D)
- Difficulty levels (Facile, Moyen, Difficile)
- Categories for better tracking
- Detailed explanations for each answer

**Interactive Flow:**
1. Student requests exam on specific subject
2. Bot presents random question with options
3. Student responds with letter choice
4. Bot provides immediate feedback and explanation

**Example Commands:**
- "Teste-moi en anatomie"
- "Donne-moi un QCM sur la biochimie"
- "Question sur la pharmacologie"

## 🚀 Integration Instructions

### For Each HTML Page:

**1. Add CSS in `<head>`:**
```html
<link rel="stylesheet" href="css/chatbot.css">
```

**2. Add FontAwesome (if not already present):**
```html
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">
```

**3. Add JavaScript before closing `</body>`:**
```html
<script src="js/chatbot.js"></script>
<script>
    document.addEventListener('DOMContentLoaded', () => {
        if (!window.medEduChatbot) {
            window.medEduChatbot = new MedEduChatbot();
        }
    });
</script>
```
